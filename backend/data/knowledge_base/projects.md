# Key Projects — Shubham Singh

## Brain Tumor Detection and Classification
**Category:** Computer Vision / Medical AI
**Accuracy:** 94%
**Dataset:** Kaggle LGG MRI Segmentation Dataset
**Description:** Developed a two-stage pipeline for brain tumor analysis:
1. U-Net model for pixel-level tumor segmentation in MRI images
2. ImageNet-based CNN classifier for tumor type classification
Integrated patient metadata for risk prediction and severity estimation.
**Tech Stack:** Python, TensorFlow, Keras, U-Net, Pandas, NumPy, Kaggle

## Indian Sign Language Detection
**Category:** Computer Vision / Accessibility AI
**Description:** Real-time hand sign detection system for Indian Sign Language (ISL):
- Uses MediaPipe for hand landmark extraction (21 keypoints per hand)
- Random Forest classifier trained on landmark coordinates for letter classification
- Accurately classifies ISL alphabets from webcam feed for real-time translation
- Designed to help bridge communication barriers for hearing-impaired individuals
**Tech Stack:** Python, MediaPipe, Scikit-learn, Random Forest, OpenCV

## Machine Learning-Based Legal Petition Decision Prediction
**Category:** NLP / Machine Learning / Research
**Accuracy:** 91.3%
**Dataset:** ILDC (Indian Legal Documents Corpus)

**Tech Stack:** Python, Scikit-learn, Random Forest, NLP, Pandas

## IoT Safety Device for Mining Workers
**Category:** IoT / Embedded Systems
**Description:** Hardware-software safety system for hazardous mining environments:
- NodeMCU (ESP8266) as the central controller
- MQ-4 methane/gas sensor for toxic gas detection
- DHT11 sensor for temperature and humidity monitoring
- Pulse sensor for worker heart rate monitoring
- Real-time alerts and dashboard via Blynk IoT platform
- Improves on-site safety by enabling early hazard detection and worker wellness monitoring
**Tech Stack:** NodeMCU, C++, Blynk, MQ-4, DHT11, Pulse Sensor, Arduino IDE
